# Sanity schema (CLI only)

Pure content schema for project `bxr88bn5` / dataset `production`. There is no hosted Studio; editing happens in [`../admin`](../admin).

```bash
npm run typegen --prefix sanity
npm run schema:deploy --prefix sanity
```

Typegen writes [`../src/sanity.types.ts`](../src/sanity.types.ts) for the public site.
